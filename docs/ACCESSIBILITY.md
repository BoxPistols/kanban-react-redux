# アクセシビリティ / モバイル対応基準

このプロジェクトの UI が守るべき最低基準。新規コンポーネント追加時もこの基準に従う。
共通スタイル断片は `src/a11yStyles.ts` にある。

## フォントサイズ

- **最小 12px。** これ未満のフォントサイズは使用しない
  (根拠: 視認性。バッジ・キャプション・ヒントも 12px 以上)。
- 本文・カードタイトルは 14px 以上。
- `font-size: 0` はテキストを視覚的に隠す用途(ロゴの `KB` 置換)にのみ許可。
- **モバイル(≤768px)の input / textarea / select は 16px 固定**
  (GlobalStyle で `!important` 指定)。16px 未満だと iOS Safari が
  フォーカス時に自動ズームして画面が跳ねるため。

## タッチターゲット

- **常時 24×24px 以上**(WCAG 2.5.8 AA のハード下限)。
- **タッチデバイス(`pointer: coarse`)では 44px 相当**(Apple HIG)。
  - 単独配置のアイコンボタン → `touchTargetExpand`(a11yStyles)で
    視覚サイズを変えず当たり判定だけ 44px に拡張する。
  - **隣接して並ぶボタン群には拡張を使わない**(当たり判定が重なり
    誤タップの原因になる)。実サイズを 40〜44px に引き上げる。
- ボタン部品(`Button.tsx`)は標準 36px / タッチ 44px、
  小型は 28px / タッチ 44px が組み込み済み。

## hover 依存の禁止

- hover でしか現れない操作(opacity: 0 → hover で表示)は、
  タッチ環境では「見えないのにタップできる」事故になる。
  - 補助的な操作で代替経路がある場合 → `@media (hover: none)` で **非表示**
    (例: カード面の編集/削除ボタン。モーダルから同操作が可能)。
  - 代替経路がない場合 → `visibleWithoutHover(opacity)` で **常時表示**
    (例: レーンの畳むボタン、画像の削除ボタン)。

## iPhone / iOS Safari 固有

- viewport は `viewport-fit=cover` + セーフエリア(`env(safe-area-inset-*)`)を
  ヘッダー・トーストで考慮済み。`user-scalable=no` は使わない(ズーム禁止は不可)。
- 高さは `100dvh` を優先(ツールバー伸縮に追従)。`100vh` はフォールバック。
- カードの `touch-action: manipulation`: 指スクロールを妨げない。
  ドラッグ開始は TouchSensor の長押し(220ms)判定で行う。
- タップハイライトは無効化し、フォーカス表示は `:focus-visible` に統一。

## 検証方法

Playwright + iPhone エミュレーションで自動監査できる
(全可視テキストの computed font-size、全操作要素の実効ターゲットサイズ
(::after 拡張込み)、横オーバーフロー、hover 依存の有無)。
リリース前に少なくとも: ボード画面 / カード詳細モーダル / モバイルドロワー
の 3 画面で違反 0 を確認する。
